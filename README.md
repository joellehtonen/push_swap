# Push_swap
---
## What is this?

- This is our first algorithm project, where we had to develop a method to arrange a stack of random numbers into an order of smallest to biggest, using as few moves as possible.

---

## How it works?
- Make the file using `make`.
- Enter a sequence of numbers as an argument to the program, for example `./push_swap 3 5 2 1 9 8 7`
- The program will output the moves it did to arrange the numbers from smallest to biggest.
- Use `wc -l` to find out how many moves it took!
---

## What I learned?

- I learned about stacks, how they work. Thinking about how to move the numbers around, how to find out which one belongs where, how to arrange them most efficiently, was a nice challenge that I enjoyed thinking about very much.
- I also studied other number sorting algorithms for this, and found the different approaches fairly interesting. I tried to make quicksort work, but in the end abandoned it, as it took too many moves. In the end, I used my own version of the "turk" system. 

---

## What I would do differently?

- Afterwards I found out how radix sort really works, and while it isn't the most efficient, I found it's simplicity to be really beautiful, and I would strongly consider using it, if I were ever to do this again.
