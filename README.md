# Push_swap
---
## What is this?

- This is our first algorithm project, where we had to develop a method to arrange a stack of random numbers into an order of smallest to biggest, using as few moves as possible.

---

## What I learned?

- I learned about stacks, how they work.
- Honestly, thinking about how to move the numbers around, how to find out which one belongs where, was a nice challenge that I enjoyed thinking about very much.
- I also studied other number sorting algorithms for this, and found the different aprroaches fairly interesting. I was tried to make quicksort work, but in the end abandoned it, as it took many moves. In the end, I used my own version of the "turk" system. 

---

## What I would do differently?

- Afterwards I found out how radix sort really works, and while it isn't the most efficient, I found it's simplicity to be really beautiful, and I would strongly consider using it, if I were ever to do this again.
